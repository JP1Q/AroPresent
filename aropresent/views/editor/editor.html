Slide commands

Put each one on its own line.

\col1, \col2, ...
Split the slide (or box) into columns
\d ... \end
A box you can style (\end is optional at the end of a slide)
\fontsize{24}
Text size in px (36 is normal)
\color{red}
Text color
\bg{#222}
Background
\align{center}
left, center or right
\style{padding: 8px}
Any CSS

Styles apply to the box they're in, otherwise to the column or the whole slide.
